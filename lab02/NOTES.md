Рабочая папка — это файлы проекта на диске, с которыми я работаю напрямую. Индекс (staging area) — это промежуточная область: изменения, которые я отметил через git add и готов зафиксировать. Коммит — это снимок состояния проекта на определённый момент, который сохраняется в историю.




Git — это система контроля версий, которая работает локально на компьютере. GitHub — это платформа для хранения репозиториев и совместной работы. Git работает без GitHub, а GitHub без Git — нет.

git diff сравнивает рабочую папку с индексом — показывает, что изменилось, но ещё не добавлено через git add. git diff --staged сравнивает индекс с последним коммитом — показывает, что попадёт в следующий коммит.
